HOW TO ADD YOUR IMAGES
=======================

Drop your photos into the folders below using the exact file names listed.
The website already points to these paths, so images will appear
automatically once added — no code changes needed.

/public/images/logo.png                  -> Your logo (already added)

/public/images/hero/
  hero-student.jpg                       -> Main hero photo (homepage)

/public/images/founder/
  founder.jpg                            -> Founder photo

/public/images/courses/
  kids.jpg, certificate.jpg, diploma.jpg, drawing.jpg, painting.jpg,
  fine-arts.jpg, art-craft.jpg, teacher-training.jpg, professional.jpg

/public/images/art-forms/
  pencil-drawing.jpg, colour-pencil.jpg, charcoal.jpg, oil-pastels.jpg,
  soft-pastels.jpg, acrylic-painting.jpg, watercolour.jpg,
  fabric-painting.jpg, portrait-art.jpg, texture-art.jpg,
  oil-painting.jpg, sculpture-painting.jpg, mixed-media.jpg

/public/images/student-works/
  work-1.jpg through work-9.jpg

/public/images/testimonials/
  student-1.jpg, student-2.jpg, student-3.jpg

/public/images/awards/
  award-1.jpg, award-2.jpg, award-3.jpg, award-4.jpg

/public/images/videos/
  video-1.jpg, video-2.jpg, video-3.jpg, video-4.jpg  (thumbnails)

Until a real image is added, that spot shows a clean branded placeholder
instead of a broken image icon — so the site never looks broken while you
collect real photos. To add or rename items (e.g. a 10th course), edit the
matching file in /src/data/.
